## Introduction

The **admin assistant** is the staff chat that lives in the ReadyIntelligence admin. Open it
from the sparkle control in the header — it docks beside your work rather than being embedded
on a public website.

It is still an [assistant](./assistants.md) backed by an [admin / automation agent](./agents.md).
That agent decides how it answers and which [tools](./tools.md) and [skills](./skills.md) it
can use. You do not embed this assistant on your site; website visitors never see it.

Typical things you can ask it to do:

- Create or refine a [skill](./skills.md) from your knowledge base
- Check this period's [credit usage](./credits.md)
- Add or inspect a [knowledge source](./knowledge-base.md)
- Keep your agents and website assistants on track
- Summarise what was said in past conversations

## Homescreen

When you open the assistant on a **new chat**, you see its homescreen:

| Element | What it is |
|---------|------------|
| **Greeting** | The main welcome line, e.g. "Hi, I'm RI." |
| **Sub-text** | An optional line under the greeting that explains what the assistant can help with. |
| **Suggested prompts** | Up to three starter questions. These show on a new chat and hide once you have recent threads. |

Start a conversation from a suggestion, or type your own question. Existing threads stay in
the assistant so you can pick up where you left off.

## Configuring the admin assistant

In the admin you can choose which **tools**, **skills**, and **scheduled calls** the assistant
has — the same kinds of settings you would set on any other admin / automation agent. Only
tools and skills that are appropriate for staff use are offered.

The assistant inherits capabilities through its default agent. You do not assign skills on the
assistant record itself.

### Personal skills

When personal skills are enabled for your site, each admin user can keep skills that are
available **only to them** in this assistant. They are never assigned to website assistants,
scheduled agents, or MCP endpoints. See [Skills](./skills.md#global-and-personal-skills).
